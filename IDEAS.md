# Отложенные идеи (вернуться позже)

Записано, чтобы следующая сессия Claude могла продолжить с того же места.
Пользователь общается по-русски, в технике не разбирается: объяснять просто и пошагово.

## 1. Приложение для изучения языков (почти как Duolingo)
- Идея: своё приложение для изучения языков, начали с итальянского.
- Автоматическая работа с аккаунтом Duolingo из облака не подходит: duolingo.com закрыт сетью окружения,
  Google блокирует автоматический вход, это против правил Duolingo, а их контент копировать нельзя.
- Предложение: Claude сам составит свой курс итальянского (уровни, слова, фразы, упражнения, повторения).

## 2. Minecraft: стеклянная решётка с фонарями (сделано)
- Сборка: DeceasedCraft (Forge, Minecraft 1.18.2), лаунчер Prism.
- Датапак в папке `minecraft-pyramid/` (ветка `claude/duolingo-cloud-code-automation-8annjn`).
- Главные команды: `/function pyramid:lattice_small|medium|large|huge`, удаление: `lattice_remove_*`.
- Ждём скриншот из игры, чтобы сравнить с видео и подогнать.

## 3. Игра в жанре сталкера на Unreal Engine 5.8
- Компьютер: RTX 4060 Ti 8 ГБ (MSI), 32 ГБ ОЗУ 5200, мощный процессор и SSD.
- Подключение Claude Code к Unreal: официальный плагин Epic
  (`/plugin install unreal-engine-skills-for-claude-code@claude-plugins-official`,
  в редакторе плагины ModelContextProtocol + AllToolsets, консоль `ModelContextProtocol.StartServer`).
- Графика в духе S.T.A.L.K.E.R. 2: UE5 (Lumen, Nanite) + Quixel Megascans + наборы с Fab.
- Карта в духе Чернобыльской зоны, зданий мало, в основном природа. Рельеф можно взять из открытых данных
  о реальной местности. Карту и модели из S.T.A.L.K.E.R. 2 не копировать, игра должна быть своя.
- Начать с локации 1×1 км. Примерные сроки: 1×1 км за 1–2 мес., 4×4 км за 6–12 мес., 8×8 км за 1,5–3 года.
- Ещё не выбрано: мир/сюжет (варианты: «Мёртвая зона», «Карантин», «Провал»), название игры.
- Спрашивал про карту как в Forza Horizon 4: размер возможен (World Partition + PCG), детализация вручную — нет.

## 4. Подарок для девушки (её любимая страна и язык)
- Пользователь узнал у девушки её любимую страну и язык (какие именно, ещё не сказал).
- Идеи: сайт-открытка про её страну с тёплыми словами на её языке, мини-урок фраз на её языке для пользователя,
  викторина про страну с посланием в конце, свидание в стиле её страны.

## 5. Cinema 4D + Claude
- Официальный MCP-сервер Maxon: Cinema 4D 2026.4+, Windows/Mac, бесплатно.
- Включение: Edit → Preferences → MCP → Allow MCP Server; Clients → Claude Desktop → Update Selected Client.
- Claude может сам рендерить и смотреть результат. Хорошо выходят предметы, сцены, свет, материалы, анимация, MoGraph;
  персонажей и живых существ лучше брать готовыми.
- Версию Cinema 4D пользователя ещё не узнали.
